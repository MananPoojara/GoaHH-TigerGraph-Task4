# Raw benchmark data

The official `transactions.csv`, `identity.csv`, `closed_cases_history.csv`, `case_pack.csv`, and challenge README are stored here locally and ignored by Git. Verify them against `data/source-manifest.json`; do not rename IDs or use public IEEE-CIS labels.

The profiling baseline and exact card-ID derivation are documented in `docs/15-source-data-profile.md`. Never treat `card1` alone as a Card ID.
